YOURSSU 피어리뷰 HTML · PDF 생성기

실행
1. start.cmd를 더블클릭합니다.
2. 브라우저에서 생성기 화면이 자동으로 열립니다. 기본 포트는 8765이며, 이미 사용 중이면 8775까지 자동으로 빈 포트를 찾습니다.
3. data.xlsx와 info.xlsx를 선택하고 파일 분석을 누릅니다.
4. 자동으로 찾은 열을 확인한 뒤 전체 HTML + PDF ZIP 생성을 누릅니다.

결과
- 사람별 HTML
- 사람별 PDF
- validation-results.json
- 위 파일을 포함한 ZIP 하나

PDF 안정성
- 프로그램에 포함된 고정 버전 Chromium으로 PDF를 만듭니다.
- Wanted Sans를 로컬에서 불러오고 폰트 로딩이 끝난 뒤 생성합니다.
- 본문 글자는 선택하고 검색할 수 있는 실제 텍스트입니다.
- 텍스트 잘림, 페이지 경계 이탈, 카드 내부 안전 여백, 요소 겹침, 빈 페이지를 검사합니다.
- 검증 오류가 한 건이라도 있으면 해당 PDF와 전체 ZIP 생성을 중단합니다.

주관식 카드 자동 배치
- 90자 이하, 91~140자, 141~260자, 261자 이상을 1차 분류한 뒤 실제 렌더링 높이로 다시 검사합니다.
- 4개/3개/2개/1개와 혼합 길이 전용 레이아웃을 자동 선택합니다.
- 카드 본문은 항상 16pt를 유지하며 글자를 줄이거나 내용을 생략하지 않습니다.
- 장문은 문장 경계에서 다음 페이지로 이어지고, 단독 카드 페이지는 각 섹션의 마지막에 배치됩니다.

종료
- stop.cmd를 더블클릭합니다.

주의
- runtime 폴더를 삭제하거나 일부 파일만 옮기면 실행되지 않습니다.
- 폴더 전체를 함께 복사하면 Node.js, Chromium, 폰트의 별도 설치가 필요 없습니다.
- 생성 결과와 로그는 각각 generated, logs 폴더에 저장됩니다.
